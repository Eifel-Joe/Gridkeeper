## Decision: one Placement group

- The group "Placement" is always shown. It holds upstream's dropdown (options `Snap to free spot`, `Center on origin`,
  kept literal, they are stored in configs) and, as before, the Cell selection only for a new bin with a baseplate or
  box in the design (`binCell.offersCellPick`).
- Priority, in one pure function `binCell.placementSource(isCentered, hasCell, hasKeptPlacement)` →
  `'cell' | 'center' | 'kept' | 'snap'`: a picked cell (also when a bin in a cell is rebuilt) wins; else Center on
  origin (also on rebuild, upstream: a centered bin is centered again, its size may have changed); else the kept
  placement of a rebuild; else snap to the free spot (`placementUtils.findPlacement`).
- The dropdown moves from the Dimensions group into the Placement group (upstream adds it to Dimensions). Its label
  becomes "Position" so the dialog doesn't read "Placement › Placement" (proposal; upstream's wiki term stays
  "Placement" in the docs text as group name).
- While a cell is picked the dropdown is greyed out (it doesn't apply then); the tooltip says the cell wins.
- Settings snapshot: instead of the whole group only the Cell input is left out, so "Position" is shown in the bin's
  settings like any setting. Rebuild reads the config (`STATE_INPUT_IDS`), not the snapshot, so this is display only.

## Tab top offset in the fork's own code

Upstream replaced the fixed `BIN_TAB_TOP_CLEARANCE` by `tabTopOffset` in its code. The fork has three more users of
the fixed value, which must follow the offset, or the parts no longer meet:
1. Raised dividers (`createRaisedDividers`, `raisedCornersBottomZ`): start at the lowered divider top
   (`binBodyTotalHeight - tabTopOffset`) and reach the lip top as before (height = offset + lip extra − trim).
   With offset 0 no top clearance cut is made (upstream), the raised dividers start at the body top.
2. Cullenect sockets in `binBodyGenerator` and in the shelled-bin path of `binBuilder`: `tabTopClearance(style)` →
   `tabTopClearance(style, tabTopOffset)`. The socket is cut into the tab top, so the insert fits the same at every
   offset; insert and label just sit lower.
3. `configJson.MM_FIELDS`: union of our `cullenectSocketOffset` and upstream's `tabTopOffset`.
With the default 0.5 mm all geometry stays as before.
