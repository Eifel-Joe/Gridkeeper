# Round 39: box build and rebuild faster; rebuild preview hides the old set without an error

Points: p480, p296 (speed), p481 (preview). Box after Pred's parametric Gridfinity Storage Box v1.1
(https://www.printables.com/model/543553, CC BY-NC, by Pred), drawn in code.

## What was measured (Fusion 2706.1.17, scripts fusion-auftraege/r39_probe.py, r39_probe2.py)

Cost of single Fusion calls, ms per call:

| Call | empty document | one box in it | 900 dimensions in it | 900 fixed points in it |
|---|---|---|---|---|
| Parameter.expression | 2.2 | 144 | 107 | 7.5 |
| addDistanceDimension | 3.3 | 42 | 20 | 10 |
| Sketches.add | 15 / 5 | 206 | 118 | 10 |
| ExtrudeFeatures.addSimple | 22 | 180 | – | – |
| SketchPoint.isFixed | 0.5 | – | 8.8 | 5.2 |

- Hiding the other sets (light bulbs off) changes nothing (150 ms). Rolling the marker to the start makes it worse
  (223 ms). The cost doesn't come from computing geometry but from the number of model parameters in the document:
  900 dimensions alone (946 parameters) make an expression 107 ms, 900 fixed points (no parameter) 7.5 ms.
- A box brings ~900 sketch dimensions (894 `addDistanceDimension`, 808 of them from `predSketch.WorldSketch._apply`),
  each a model parameter. Every box makes every later call dearer, its own calls included (quadratic in a build).
- A sketch with 900 fixed points and lines between them is fully constrained (`isFullyConstrained` True).
- Edge lists: `list(body.edges)` 6.7 s against `edges.item(i)` over `count` 3.1 s for 5270 edges (the swig iterator
  asks `len` before every item). A build reads ~34 000 edges (R36: 34 375 `__len__` + 34 294 `item` calls, 18 + 18 s).
- p481: Fusion never suppresses a box set's group (`Cannot suppress/unsuppress group. Some group features are not
  suppression-configurable.`), every one of its 298 items suppresses on its own (3.7 s, none refused), which is why
  the old set was hidden all the same. Turning off the set occurrence's light bulb hides all 13 bodies at once (0.00 s).
- Deleting the old group item by item: 295 ms per item with the marker after the items (today), 192 ms with it before
  them (different items, not conclusive). `Design.deleteEntities` reported success but removed 4 of 54 items; not used.

## p480 / p296: fewer parameters, fewer calls

### Requirement
Build and rebuild measurably faster, measured with the R36 script (`r36_mess.py` as `r39_mess.py`, mode full: box 1,
box 2 beside it, rebuild of box 1 as 6×4×6 with the two probe joints, preview), base and branch back to back in the
same Fusion session. Geometry unchanged (box snapshot cases), every sketch fully constrained, parameter changes act as
before, the rebuild keeps the user joints on the part at the same seat (p293).

### Options
1. Fixed points (chosen): a sketch point whose two sketch coordinates are plain numbers (no box parameter in them, Dim
   kind VALUE) never moves when a parameter changes. `WorldSketch` fixes it (`isFixed`) instead of two distance
   dimensions. No model parameter, ~1 cheap call instead of two dear ones, and every later call of this and every later
   box is cheaper. Points that hang on a parameter keep their dimensions and expressions as today. Most of the small
   parts (latch, handle pin, hinge, the handle apart from its width) are plain numbers; the box has some.
2. Collect the expressions and set them once: no API for it; every expression is one call whatever the order.
3. Defer compute (`isComputeDeferred` of the design, marker rolled back): no design-wide deferral in the API
   (`Design` has `computeAll`, `deleteEntities` only); marker at 0 measured slower.
4. Copy the identical parts from another set: the four latches, two pins, two hinges are already one component each
   (`addExistingComponent`); sharing components across sets breaks the rebuild's deletion of the old set. Not done.
5. Edge lists by index (chosen, cheap): `predBoxGenerator._pick`, the hinge's, latch's, handle's and pin's edge walks
   read edges with `item(i)` over `count` once per call.

### Decision
- `sketchChain.chain` gets the set of fixable points; a point the chain would bind with two dimensions (the anchor of a
  shape, a line end off both axes of its known neighbour, an arc's first new end, a circle centre) is fixed instead
  when fixable; a line end the chain would bind with horizontal/vertical plus one dimension is fixed instead only when
  its known neighbour is fixable too (both plain numbers, the line stays level by itself; with a neighbour that hangs on
  a parameter the condition decides where the end goes after a change, so it stays as today). Arc ends on a known centre and arc centres on a chord's bisector
  keep their single dimension (fixing them would bind the arc twice). `rank()` counts a fixed point as two conditions;
  the existing rank checks keep every chain exact.
- `WorldSketch` passes the fixable points (both sketch-axis coordinates not expressions) and applies `('fixed', p)`
  with `SketchPoint.isFixed = True`.
- Edge lists by index wherever the box code walks body edges or faces.
- Kept as is: the order and kind of the features, their parameters, the timeline group, the joint origins.

## p481 "Box-Rebuild-Vorschau: alte Gruppe lässt sich nicht unterdrücken"

### Decision
`rebuildUtils.hideOldBody(byLightBulb=True)`, used by the box rebuild only: the old set's occurrence's light bulb goes
off, nothing else; a part of bodies in the root and the other generators keep today's way (group, else items). The box
command's destroy handler turns the light bulb back on first thing, whatever ended the command
(`restoreHiddenForPreview`), should Fusion's undo of the preview not do it; a set gone with OK is left alone. Answers to the point:
the old set was hidden by the fallback (every item suppressed on its own), not by chance; the message was harmless but
cost 298 suppressions per preview. A preview is undone by Fusion; the light bulb comes back with it.

## Not part of this round
- Changing the deletion of the old group (marker, whole group): not conclusive, joints must stay (R36 Task 9).
- Fewer features, sketches or construction planes in `createPredBox`.
- Boxes already in a document keep their dimensions; only sets built or rebuilt with this code are lighter.

- `r39_mess.py` base (5f42fb4) and branch back to back: box 1, box 2, rebuild and preview each faster on the branch;
