# Datenschutz { #privacy }

Gridkeeper erhebt keine personenbezogenen Daten. Es hat kein Konto, keine Analyse und kein Tracking und sendet von sich
aus nichts über Sie oder Ihre Konstruktionen irgendwohin. Einstellungen, die es speichert (Vorgaben, gespeicherte
Eingaben), bleiben auf Ihrem Rechner.

Nur in diesen Fällen greift es auf das Internet zu:

| Wann | Was geschieht |
|---|---|
| **Update-Prüfung**, einmal täglich beim Start von Fusion | Gridkeeper fragt GitHub (`api.github.com`) nach der Liste seiner Releases. GitHub sieht Ihre IP-Adresse und die Anfrage, sonst wird nichts gesendet. Schalten Sie die Prüfung unter **Dienstprogramme › Zusatzmodule › Gridkeeper Updates** ab, siehe [Installation und Updates](../getting-started/installation.md). |
| **Jetzt aktualisieren**, wenn Sie darauf klicken | Gridkeeper lädt die Release-ZIP von GitHub herunter. |
| **Kopieren und Issue öffnen**, wenn ein Erstellen fehlgeschlagen ist und Sie darauf klicken | Ihr Browser öffnet ein neues GitHub-Issue mit dem ausgefüllten Fehlerbericht, siehe [Meldungen und gesperrtes OK](../help/messages.md). Sie sehen den Text und entscheiden, ob Sie ihn absenden. |
| **Links** in den Dialogen und auf diesen Seiten | Sie öffnen sich in Ihrem Browser, auf GitHub, Printables oder der genannten Seite. |

Was GitHub mit Anfragen an seine Server tut, ist in der
[Datenschutzerklärung von GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
dargelegt. Diese Seiten werden ebenfalls auf GitHub Pages gehostet.
