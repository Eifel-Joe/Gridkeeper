# Privacy

Gridkeeper collects no personal data. It has no account, no analytics and no tracking, and it sends nothing about you
or your designs anywhere on its own. Settings it saves (defaults, saved inputs) stay on your computer.

It talks to the internet in these cases only:

| When | What happens |
|---|---|
| **Update check**, once a day when Fusion starts | Gridkeeper asks GitHub (`api.github.com`) for the list of its releases. GitHub sees your IP address and the request, nothing else is sent. Turn the check off in **Utilities › Add-Ins › Gridkeeper updates**, see [Installation and updates](../getting-started/installation.md). |
| **Update now**, when you click it | Gridkeeper downloads the release ZIP from GitHub. |
| **Copy and open an issue**, when a build failed and you click it | Your browser opens a new GitHub issue with the error report filled in, see [Messages and locked OK](../help/messages.md). You see the text and decide whether to send it. |
| **Links** in the dialogs and these pages | They open in your browser, on GitHub, Printables or the site they name. |

What GitHub does with requests to it is set out in the
[GitHub privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
These pages are hosted on GitHub Pages as well.
