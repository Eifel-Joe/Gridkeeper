# Runde 13 – Baugruppe und Einleger per Joint, Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bin, Baseplate und Einleger als Komponenten in den Sammelkomponenten Grid/Bins/Label bauen. Eigenfarbige
Beschriftung kommt in „Text“. Taschen und Einleger bekommen Joint Origins. Der Label-Befehl setzt den Einleger per
Joint in eine gewählte Tasche, und ein Bin-Rebuild hält diesen Joint.

**Architecture:** Reine Entscheidungen, die sich ohne Fusion testen lassen (wohin gebaut wird, Namen, Passt-Prüfung,
Joint-Zuordnung), kommen in Module ohne `adsk`. Mit pytest getestet. Die Fusion-Seite bündelt ein neues Modul
`lib/gridfinityUtils/assembly.py`: Sammelkomponente finden oder anlegen, Teil- und Text-Occurrence mit vollem Pfad,
Umstellung auf hybrid samt Rücknahme. Die Generatoren bekommen für die Beschriftung eine zweite Zielkomponente (Weg A
der Spec). Geprüft wird in Fusion über die Snapshot-Tests mit einer neuen, allgemeinen Strukturprüfung, dazu ein
Ende-zu-Ende-Skript.

**Tech Stack:** Python 3, Fusion API (`adsk.core`, `adsk.fusion`), pytest mit `tests/stubs`.

**Spec:** `docs/specs/2026-11-15-runde-13-design.md` (freigegeben 15.11.)

## Global Constraints

- Längen im Code in cm, Testfälle und Attribute für Jörg in mm.
- Jede Skizze des Generators ist vollständig bestimmt (`Sketch.isFullyConstrained`).
- Nach jedem Bau, auch nach einem Fehler, ist die Wurzel aktiv (`des.activateRootComponent()` im `finally`).
- Teile, die vor dieser Runde gebaut wurden, bleiben beim Rebuild, wo sie sind: Körper in der Wurzel, oder eine
  Komponente direkt in der Wurzel.
- Geometrie und Maße aller Körper bleiben gleich. Die vorhandenen Snapshots werden nicht neu abgelegt.
- Namen in Dokumenten sind wörtlich: „Grid“, „Bins“, „Label“, „Text“, „Text placement“, „Pocket joint origin“,
  „Compartment N pocket joint origin“, „Insert joint origin“.
- Credits wie in der Projekt-CLAUDE.md: CHANGELOG nennt Le0Michine, CullenJWebb, ostat / Chris Heazlewood und
  Zack Freedman.

## Review Focus

1. **Rebuild einer Bin, die in „Bins“ liegt:** Die neue Bin muss wieder in „Bins“ landen, an derselben Stelle. Nicht in der
   Wurzel, und auch nicht doppelt verschoben, weil `transform2` relativ zur Eltern-Komponente gilt. → Task 3, Fusion-Fall
   `bin_rebuild_in_container` im E2E-Skript (Task 9).
2. **Sammelkomponente vom Nutzer gelöscht oder umbenannt:** Umbenannt wird sie über das Attribut wiedergefunden.
   Gelöscht wird sie neu angelegt, kein Absturz. → Task 2, E2E-Skript.
3. **Einleger mit Live-Text verlängert:** Die neuen Buchstaben müssen in „Text“ liegen. → Task 4, vorhandener Fall
   `label_1u_welle_6mm_text_edited` mit Strukturprüfung (Task 9).
4. **Tasche aus einer gelöschten oder neu gebauten Bin noch im Auswahlfeld:** Der Bau darf nicht mit einem ungültigen
   Proxy abbrechen. Dann gilt: keine gültige Tasche, Hinweis. → Task 7.
5. **Fehlschlag mitten im Bau in einem Bauteil-Dokument:** Das Dokument wird wieder ein Bauteil, keine leere
   Sammelkomponente bleibt zurück. → Task 2 (Rücknahme löscht alle neuen Occurrences der Wurzel).
